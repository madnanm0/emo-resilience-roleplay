# EMO – Emotional Resilience Roleplay World 🌱

**EMO** is an AI-powered interactive storytelling tool that helps users build emotional resilience through decision-based roleplay. It uses GPT-4 and CBT (Cognitive Behavioral Therapy) principles to simulate emotionally challenging scenarios and provide personalized, empathetic guidance.

---

## 🎯 Features

- 🧠 Scenario-based emotional decision-making
- 💬 GPT-4 driven conversational feedback
- 🧘 CBT-based coping strategies
- 🎨 Built with Streamlit for fast, clean deployment

---

## 🚀 Tech Stack

- Python 3.10+
- Streamlit
- OpenAI API
- Deployed using Streamlit Cloud

---

## 📦 Installation (Local)

```bash
git clone https://github.com/your-username/emo-resilience-roleplay.git
cd emo-resilience-roleplay
pip install -r requirements.txt
```

Create a `.streamlit/secrets.toml` file with:

```toml
OPENAI_API_KEY = "your-openai-key-here"
```

Then run:

```bash
streamlit run app.py
```

---

## 🌐 Deployment (Streamlit Cloud)

1. Push to GitHub
2. Deploy via https://share.streamlit.io/
3. Add your OpenAI API key under Secrets:

```toml
OPENAI_API_KEY = "sk-xxxxxxxxxxxxxxxxxxxx"
```

4. Done ✅
